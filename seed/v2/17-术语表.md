# 术语表

按"容易混"排序，不按字母序。每条给出中文、英文、定义、以及最容易和什么混。

| 术语 | 英文 | 定义 | 易混于 |
|---|---|---|---|
| 语义卡 | semantic card | 描述一张表或一个指标的结构化配置，是模型生成 SQL 的唯一事实来源 | 不是数据库表本身 |
| 表卡 | table card | tables.yml 中的一个表条目，含列、粒度、坑与 join 关系 | 与「指标卡」并列 |
| 指标卡 | metric card | metrics.yml 中的一个指标条目，含公式、单位、坑 | 不含 SQL 模板 |
| 输出约定 | output contract | defaults.yml 里的行数、小数位、最小样本量等全局约束 | 不是提示词里的常量 |
| 规则基线 | rule baseline | 无 LLM 时用关键词匹配直接生成 SQL 的兜底路径 | 能力弱但零成本 |
| 判定器 | judge | 判定检索证据是否足以回答问题，不足则拒答 | 判定对象是证据不是答案 |
| 锚点 | anchor | 判定器从证据中摘录的原文句，注入作答提示词防止模型自我否定 | 必须逐字摘录 |
| 采集器 | retriever | 从语义卡里召回候选表/指标/范例的模块 | 本项目是手写 BM25 |
| 检查点 | checkpoint | 编排图每个节点后的状态快照，可回放 | 不是数据库事务 |
| 跨度 | span | trace 中的一次可观测操作，含耗时与属性 | 父 span 下可挂多个子 span |
| 粒度 | grain | 一行数据代表什么，是 join 前必须先确认的东西 | 与「粒度」在数仓语境同义 |
| 同环比 | YoY / MoM | 同比对去年同期，环比对上一期 | 同比不是「上个月对比」 |
| 末次归因 | last-touch | 把转化记给最后一次点击的渠道 | 与首次归因结论常相反 |
| 留存窗口 | cohort window | 新客注册后第 N 天的活跃情况 | 不是「N 天内任意一天」 |
| 结果集等价 | result-set equivalence | 评测时比对执行结果而非 SQL 字符串 | 列顺序可不同，值必须一致 |
| 拒答 | abstention | 证据不足时明确说不知道，而非编造 | 拒答算对，误答算错 |
| EX | exact match by result set | 结果集完全一致的题目占比 | 本项目主指标 |
| 消融 | ablation | 逐个关掉组件看指标变化 | 不是调参 |
| 静默回落 | silent fallback | 配置非法时用默认值继续，不报错 | 有意为之的设计 |
| 热重载 | hot reload | 不重启进程重新加载配置 | 失败时保留旧配置 |

## 三个被用坏的词

**"准确率"**。在这个产品里没有单一准确率。结果集等价（EX）是一个数，
拒答正确率是另一个数，SQL 语法可执行率是第三个数。说"准确率 90%"
必须带上口径，否则无法比较。本项目的 90.0% 特指"30 道可答题中结果集完全一致的比例"，
分母不含 10 道拒答题。

**"幻觉"**。在 Text-to-SQL 语境下，"幻觉"至少有三种：编了不存在的表、
编了不存在的列、算对了但口径错了。前两种能被 G03/G04 挡住，
第三种挡不住，只能靠金标题暴露。说"降低了幻觉"时要说清是哪一种。

**"实时"**。埋点延迟最长 6 小时，所以"实时看板"在本项目里指 T+1 的日粒度，
不是秒级。任何写着"实时"的地方，实际含义都是"当日数据次日可见"。
